LiquidDock 是一个面向 HyperOS 3 平板的 LSPosed 模块，可自定义桌面布局和 Dock，为多任务、文件夹、小组件、系统界面及部分应用提供液态玻璃效果。

> **版本说明：** 本 README 介绍当前 `main` 的功能（2.7.0 已准备发布）。[GitHub Releases](https://github.com/yu4032/LiquidDock/releases) 中已发布的 APK 可能尚未包含这些改动；请以对应版本的 [更新日志](CHANGELOG.md) 为准。

## 主要功能

### 全新设置界面

设置界面采用 **MIUIX + Prismal** 玻璃设计，按桌面布局、Dock、液态玻璃、第三方应用和动画等功能分类。顶部与底部具有玻璃外观；深色主题、关闭玻璃时的卡片和按钮也保留清晰边界。

- **滑块**：手指拖动时连续移动，右侧数值实时显示最近有效档位；允许即时调整的参数随显示值更新，松手保留弹性动画。涉及小组件越界检查的网格设置会先验证再保存。
- **数值输入**：点击数值可直接填写，或使用加减、重置按钮；数值变长时不会把相邻标签挤来挤去。
- **弹窗**：数值输入、恢复默认、网格警告和重启作用域对话框带有出现及退出过渡；重启作用域支持滚动列表和多选。
- **底部导航**：玻璃胶囊可拖动切换分类，图标和文字高亮随选中项移动。
- **IOS玻璃效果**：可开关设置界面玻璃外观，不影响桌面各处玻璃功能的独立开关。

### 液态玻璃

开启 LiquidDock 和液态玻璃总开关后，可以为以下界面加入统一的液态玻璃效果；图标、小组件、文件夹、多任务按钮和各类扩展界面还需开启对应功能：

- Dock；
- 桌面图标和 Dock 功能图标；
- 小组件；
- 小文件夹和大文件夹；
- 拖动中的图标、小组件和文件夹；
- 长按桌面图标弹出的快捷菜单；
- 多任务界面的“清除全部”和设备互联操作按钮；
- 桌面卸载、移除和二次确认弹窗；
- 应用顶部的分屏、小窗等控制菜单；
- 安全中心侧边栏；
- MIUI 系统搜索主界面；
- Gboard 悬浮键盘及相关工具栏。

可以单独调整模糊、折射、色散、颜色、亮度、阴影、高光、圆角和不同类型的高光层。「折射率 IOR」会影响边缘透镜弯曲；「透镜折射倍率」可独立调整，最高为 8。降低背景采样分辨率时，仍尽量保持玻璃轮廓、折射边缘和高光清晰。

多数外观调整可在**已有 Hook 正在运行**时即时应用；若目标 Hook 尚未安装，或修改的是网格等结构性设置，仍可能需要重启对应作用域。

### 桌面布局

开启“自由主界面网格”后，横屏可选 **2–10 列、2–6 行**，竖屏交换行列，保留横竖屏布局位置记忆。该开关开启时，可分别调整横屏与竖屏的：

- 水平距离；
- 顶部和底部距离；
- 行距；
- 页面指示器位置；
- 小组件尺寸适配。

缩小行数或列数时，如果桌面已有 **4×2 小组件**无法适配目标布局，设置界面会先检查并提示，而不是直接保存危险的网格尺寸；修改网格后建议重启桌面。

“自定义图标大小”有独立开关，不依赖自由网格。开启后，工作区、Dock、小文件夹、文件夹内图标和工作台应用页共用一个缩放比例，侧边栏应用页和搜索页不跟随这项缩放。

### Dock

开启 Dock 自定义后，可以调整尺寸、位置、图标间距等参数。Dock 设置还包括描边、阴影和分隔线，其中描边和分隔线使用各自开关：

- 宽度和高度；
- 底部位置；
- 图标间距；
- 模糊和圆角；
- 描边；
- 整体阴影和描边阴影；
- 分隔线。

手机互联入口可以单独隐藏，不会关闭系统本身的互联功能。

整体阴影需同时开启 Dock 自定义和阴影；描边阴影需同时开启描边和描边阴影。手机互联入口隐藏、最近应用黑名单与分隔线不依赖 Dock 尺寸自定义。

最近应用黑名单可以阻止指定应用出现在 Dock 最近应用推荐区。

出现壁纸闪烁时，可尝试开启可选的壁纸 GPU 渲染开关；该选项还要求 LiquidDock 和液态玻璃总开关开启，以及 System Framework（`system`）作用域并重启设备。

### 小组件与文件夹

开启小组件玻璃后，可使用玻璃背景；深色内容适配由对应开关控制。还可在「小组件部件管理」中载入当前桌面的小组件，进入详情后进行**逐部件处理**：

- **隐藏背景部件**：选取小组件内不需要的背景区域；隐藏规则支持单独备份和恢复。
- **部件白化 · 深色适配**：将选中的 RemoteViews 文字变为白色，或将图片显示为保留原有透明度的白色图形，而不是对白化整个小组件。
- **避免规则冲突**：同一个精确部件的隐藏与白化选择会互相排斥；白化规则独立保存，不包含在隐藏规则备份中。

部件白化目前支持 **RemoteViews 的 TextView / ImageView**；MAML 脚本绘制的内部元素暂不支持。完成部件选择后需重启桌面生效。

小文件夹和大文件夹可以分别控制玻璃、尺寸和圆角。

### 快捷菜单与对话框

长按桌面图标的快捷菜单可以替换为玻璃背景，并提供适合深色背景的白色文字和图标模式。

这两项使用独立开关，都需开启 LiquidDock 和液态玻璃总开关；白色文字和图标模式不要求快捷菜单玻璃开启。

桌面卸载、移除和二次确认弹窗需在上述总开关开启后，再启用弹窗玻璃，并可设置：

- 是否保留背景压暗；
- 原生深色模式；
- 独立颜色；
- 独立模糊度；
- 恢复继承全局玻璃外观。

桌面对话弹窗还提供独立的「**全部参数**」页面，可细调折射、高光等光学属性；没有单独设置的参数继续继承全局玻璃配置，也可以一键恢复全部继承。

### 多任务与工作台

多任务界面支持：

- 调整背景壁纸模糊；
- 取消壁纸压暗；
- 为“清除全部”和设备互联按钮启用玻璃。

多任务背景模糊和取消壁纸压暗不依赖液态玻璃总开关；操作按钮玻璃则需要玻璃总开关和对应开关。启用操作按钮玻璃后，在画面尚未准备好时会保持透明背景，不再临时切回系统模糊；关闭玻璃时恢复系统原有按钮背景。

工作台模式提供 Dock **图标垂直偏移**、图标玻璃圆角、桌面水平位置和 All Apps 横竖屏间距设置。Dock 图标设置需开启工作台自定义；分隔线由独立开关控制。经验证没有明显作用的 Dock 长度偏移与图标下间距选项已从设置界面移除。

### 系统界面与安全中心

可选的系统界面适配包括：

- 应用顶部的分屏、小窗等控制菜单；
- 安全中心游戏工具箱、视频工具箱、Global Dock 和 All Apps 等已支持侧边栏界面。

这两类玻璃功能需同时开启 LiquidDock 总开关、液态玻璃总开关和对应功能开关，并依赖目标系统适配可用。目前安全中心侧边栏使用一个玻璃总开关；**Global Dock、All Apps、游戏工具箱和视频工具箱的分场景独立颜色与模糊设置尚未进入主线版本**。

### MIUI 系统搜索与 Gboard

MIUI 系统搜索可以把主界面的背景替换为液态玻璃，并单独设置颜色和模糊度，还可通过「**全部参数**」页面调整独立的折射、高光等效果；没有覆盖的参数继承全局设置。需开启模块、玻璃总开关和对应第三方玻璃配置。

Gboard 支持悬浮键盘玻璃、相关工具栏玻璃，以及独立颜色和模糊度；通过「**全部参数**」可独立调整更多光学选项，并一键恢复继承全局配置。同样需开启模块、玻璃总开关和对应第三方玻璃配置。拖动底部手柄后是否自动进入大小调整由独立设置控制，不依赖玻璃开关；该触摸适配需要成功识别键盘底栏。

### 配置、动画与备份

可以调整工作区显隐、Dock 图标恢复、按压反馈、Dock 尺寸变化和设置页面切换速度。

设置页支持：

- 恢复内置默认配置；
- 导出当前配置为 JSON；
- 导入 JSON 配置；
- 单独备份和恢复小组件隐藏规则。

首次使用会采用当前项目内置的默认配置；升级不会用默认预设整体覆盖已保存的当前设置。**但 2.7.0 起不再转换历史配置键**：只保留旧键的选项将改用新版本默认值。JSON 配置备份与系统桌面布局备份互不替代。

## 安装

**升级前请备份 LiquidDock JSON 配置和系统桌面布局。** 两者是不同备份，互不替代。尤其是从较早版本升级到 2.7.0 时，历史配置键不会自动转换；更改网格前也应保留可恢复的桌面布局。

1. 从 [GitHub Releases](https://github.com/yu4032/LiquidDock/releases) 下载最新 APK。
2. 安装后在 LSPosed 中启用 LiquidDock。
3. 根据需要勾选作用域：

| 作用域 | 用途 |
| --- | --- |
| `com.miui.home` | 必选：桌面、Dock、多任务、文件夹、小组件等核心功能 |
| `com.android.systemui` | 推荐：桌面转场，以及可选的应用顶部菜单玻璃 |
| `com.miui.securitycenter` | 仅安全中心侧边栏玻璃需要 |
| `com.google.android.inputmethod.latin` | 仅 Gboard 适配需要 |
| `com.android.quicksearchbox` | 仅 MIUI 系统搜索玻璃需要 |
| `system`（System Framework） | 仅可选的壁纸 GPU 渲染开关需要，启用后重启设备 |

4. 重启对应进程，或直接重启设备。
5. 打开 LiquidDock，根据需要开启和调整功能。

多数已加载 Hook 的玻璃外观参数可即时更新；结构性布局、首次启用的适配以及少数 Hook 安装选项仍需重启桌面、系统界面或对应应用。可在设置界面通过「重启作用域」勾选需要刷新的进程。

## 风险提示

> [!WARNING]
> LiquidDock 会修改系统桌面、系统界面、安全中心和部分第三方应用的显示行为。系统组件或应用升级后可能出现兼容问题，更新前请保留可用的恢复方式。

LiquidDock 是社区项目，与 Xiaomi、LSPosed 或其他相关项目没有隶属关系。
