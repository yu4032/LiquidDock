# LiquidDock v2.7.4

## 工作台任务栏

- **任务栏模式**：工作台 Dock 背景可贴合屏幕左右与下边缘，移除相应边缘的圆角、高光与轮廓，保持顶部玻璃效果。
- **横竖屏对齐**：改善任务栏模式中图标与玻璃背景的垂直对齐、竖屏缩放图标后的圆角比例，以及切换桌面后偶发的 Dock 玻璃背景消失问题。
- **位置可调**：保留工作台 Dock 图标垂直偏移选项，按个人布局调整图标位置。
- **桌面文件夹隔离**：修复工作台 All Apps 中的文件夹处理可能影响普通桌面大文件夹的问题。

## 解锁与返回桌面动画

- **解锁渐显**：恢复解锁时 Workspace 图标玻璃在动画末段渐显；新增独立的解锁玻璃渐显时间，默认 450 ms。
- **返回桌面渐显**：修复 Dock 图标玻璃直到动画结束才突然出现的问题，跟随原生动画末段渐显；改善独立 Dock 窗口间的坐标对齐。
- **渲染优化**：减少工作区图标玻璃在解锁与应用返回桌面时的重复提交，不改变原生动画节奏。

## 新增功能

- **组件独立阴影与描边**：Dock、桌面图标、小组件、文件夹等液态玻璃支持独立配置投影、描边与光照，未单独设置时继承全局参数。
- **精修液态玻璃边缘**：改进整周折射描边、内侧高光与柔和投影的过渡，Dock 阴影不再在玻璃边缘被裁切。
- **快捷菜单与顶部菜单独立自定义**：分别开关玻璃效果，调整颜色、模糊、折射及各自的光学参数。
- **设置搜索**：在「概览、布局、外观、更多」四个主页面顶部下拉，搜索并跳转到对应的设置页。
- **文件夹打开渐隐**：打开文件夹时，其他工作区玻璃可按独立动画时长渐隐（默认 180 ms）。
- **绵狗修改版桌面适配**：新增可选开关，修复特定修改版桌面重新加载时真实 2×2 大文件夹占位丢失的问题。**默认关闭**，不检测桌面版本，仅对有 LiquidDock 标记且数据库实际保存 2×2 的文件夹生效。

## 优化与修复

- 重新整理颜色与色散、折射、光照及阴影设置分组；区分「原生 Dock 阴影」「Dock 描边」与液态玻璃「阴影」，并更新新安装时的部分默认光学参数，不覆盖已保存设置。
- 改善弹窗、桌面图标、小组件和文件夹拖拽时的液态玻璃外侧阴影与描边裁切；拖动时按组件类型使用各自的材质参数。
- 优化设置弹窗的光学留白和显示动画，减少边缘效果被裁切的情况。
- 优化工作区静止状态下的图标、文件夹和小组件几何缓存，减少无效的重复读取；保留布局变化、动画和多任务过渡时的正常更新。
- 优化设置搜索页面和底部导航的转场同步。

## 升级提醒

- 主要适配 HyperOS 3 / Launcher 4.50。升级前建议备份 LiquidDock 配置和桌面布局。工作台任务栏为可选功能，首次启用后可按需调整图标垂直偏移。
- 新增 Hook 或第三方桌面适配开关启用后，请重启对应的桌面作用域。
- 图标、文件夹与弹窗的玻璃绘制涉及设备 GPU 和系统渲染管线，不保证所有设备都达到相同的刷新率或效果。
