# Historical Development Records

> [!IMPORTANT]
> 本目录保存 LiquidDock 开发过程中的历史计划、设计稿和验证记录。它们反映的是各文件日期对应的研究/实现状态，**不代表当前 `main` 的生产实现**。

## 当前文档

需要了解当前行为时，请使用仓库根目录文档：

- [README](../../README.md) — 用户功能、安装和支持范围
- [FEATURES](../../FEATURES.md) — 当前设置与功能
- [ARCHITECTURE](../../ARCHITECTURE.md) — 当前运行架构
- [HOOKS](../../HOOKS.md) — 当前 Hook / listener / reflection 边界
- [CONTRIBUTING](../../CONTRIBUTING.md) — 当前开发规则
- [TODO](../../TODO.md) — 当前仍未完成的工作
- [CHANGELOG](../../CHANGELOG.md) — 版本历史

## 子目录

- `plans/` — 当时的实施计划和任务拆分
- `specs/` — 当时的设计与架构方案
- `verification/` — 当时的验证、CI 和设备观察

历史文件可能包含后来已经：

- 被替换的架构；
- 删除的类或接口；
- 已完成的 TODO；
- 被否定的实验方案；
- 旧版本兼容边界；
- 旧截图/capture 路径；
- 过时的性能或时序假设。

这些内容应作为开发历史和决策背景阅读，而不是作为当前代码修改依据。
