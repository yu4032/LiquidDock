# LiquidDock v2.7.0 — 发布说明草稿

> **待发布**。以下仅列出相对 v2.6.4 新增或变化的用户可见功能。

## 全新设置界面

- 更现代的 MIUIX + Prismal 玻璃界面，顶栏、底栏、列表卡片与深色主题对比度优化，长参数列表滚动更流畅。
- 滑块保持顺滑的连续拖动与松手弹性，数值实时更新；支持点击数值直接输入，加减和重置操作同步，修复数值变化时的布局跳动。
- 数值输入、恢复默认、网格警告和重启作用域弹窗新增过渡动画；修复重启作用域勾选与滚动交互。
- 底栏胶囊拖动时图标、文字高亮跟随；关闭了页面入口划动时不必要的放大动画。

## 更多独立玻璃调节

- Gboard 浮动键盘、系统搜索、桌面对话弹窗各自新增「全部参数」，可独立调节玻璃光学参数、恢复全局继承。
- 修复折射率 IOR 对玻璃边缘折射不明显的问题，默认效果不变；透镜折射倍率上限调整为 8。
- 低分辨率背景采样时保持玻璃轮廓、折射边缘及高光清晰。
- 已加载的相关玻璃 Hook 支持多数外观参数即时生效，无需每次调整都重启应用；结构性设置仍可能需要重启。

## 桌面、小组件和多任务

- 小组件支持逐个文字/图片部件的白化和深色适配，白化与隐藏规则互斥；目前不支持 MAML 内部部件精确白化。
- 降低网格行数/列数时，若已有 4×2 小组件无法放入目标网格，会弹窗阻止保存。
- 修复多任务「清除全部」和「设备互联」玻璃按钮的背景交接，未获得有效玻璃画面时不再回退成异常的系统模糊。

## 细节改进

- 设置界面玻璃效果开关更名为「IOS玻璃效果」。
- 工作台 Dock 上间距改为更准确的「图标垂直偏移」，去掉无效的图标下间距、长度偏移滑块。
- 移除四个手动采样安全区补偿选项，自动安全区继续生效。

## 升级提醒

**本版不再转换旧配置键。** 升级前建议备份 LiquidDock 配置与桌面布局；仅有旧键而没有当前键的设置会恢复当前默认值。修改网格或首次启用未安装的 Hook 后，可能需要重启对应作用域。

SC 侧边 Dock / All Apps / 游戏及视频工具箱的**分场景独立玻璃参数尚未合并**，不属于 2.7.0。

完整更新记录见 [CHANGELOG.md](../CHANGELOG.md)。
