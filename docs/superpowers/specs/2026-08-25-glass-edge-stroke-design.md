# 玻璃边缘描边设计

## 目标

为所有液态玻璃组件增加独立的边缘描边，用几何描边覆盖小尺寸边缘光的锯齿。该功能不读取、修改或复用 Dock 背景描边设置。

覆盖范围包括 Dock 背景、Dock 图标、工作区图标、文件夹、小组件、大文件夹及工作台模式中的对应玻璃组件。

## 设置界面

在现有“描边”页面增加“玻璃边缘描边”入口，打开独立子页面。子页面包含：

- 总开关；
- 描边方式：Fill-Diff 或标准描边，两者单选；
- Fill-Diff 宽度；
- 标准描边宽度；
- 红、绿、蓝和透明度。

默认启用，默认方式为 Fill-Diff，默认宽度为 1dp，默认颜色为白色低透明度。设置使用独立键名，预设导入导出继续由现有配置系统处理。

## 渲染方式

描边在 Prismal 片元着色器内合成，使用玻璃自身的圆角 SDF，因此会自动跟随每个组件的尺寸和圆角，不增加额外 View、RenderNode 或捕获层。

Fill-Diff 与 Dock 描边保持同一几何语义：计算外轮廓和向内收缩的内轮廓，取两者覆盖率之差形成实心描边环。标准描边以边界为中心计算指定宽度的覆盖率。两种方式都使用像素覆盖平滑，不依赖设备是否支持导数扩展。

描边在 Prismal 高光计算完成后、最终输出前合成，以低透明度轮廓覆盖高光的阶梯边缘。总开关关闭或透明度为零时不改变现有画面。上一版仅扩大高光带宽的临时修复将移除，避免双重加粗。

## 数据流

配置架构定义独立玻璃描边字段，运行时玻璃配置读取这些字段，并通过 Prismal 参数对象传给批量渲染和实时 Dock 渲染。着色器使用统一 uniform，普通路径与零拷贝路径采用相同计算。

旧配置中不存在这些字段时使用上述默认值，不覆盖 Dock 描边字段，也不需要破坏性迁移。

## 验证

- 配置测试：默认值、范围、预设和导入导出均包含新字段；
- GUI 测试：描边页面存在独立入口，子页面依赖关系正确；
- 参数链路测试：配置字段抵达所有 Prismal 渲染路径；
- 着色器测试：两种模式产生不同几何，关闭时无描边，Fill-Diff 内部被挖空；
- 构建并安装到设备，重点检查小图标圆角、直边、文件夹动画及工作台模式。

## 非目标

- 不改变 Dock 背景描边的现有行为或设置；
- 不增加描边阴影、渐变色、逐组件开关或新的圆角参数；
- 不修改玻璃高光分组开关的语义。
