# LiquidDock

[English](README_EN.md)

LiquidDock 是面向 HyperOS 平板桌面的 LSPosed 模块，提供桌面网格、Dock、多任务背景和液态玻璃适配。功能是否生效取决于对应开关和作用域；填写参数不等于启用功能。

## 桌面布局

开启 LiquidDock 总开关和“自由主界面网格”后，横屏支持 2–10 列、2–6 行，竖屏交换行列。自定义网格几何、小组件尺寸适配和横竖屏位置记忆属于这条布局路径。关闭自由网格时，网格参数不会开启这条路径。

当前主线对 1×1 图标保留系统 Pad 挤压规划器，多格项使用通用矩形规划器。

“自定义图标大小”是独立功能，需要总开关和自身开关，不要求自由网格。工作区、Dock、小文件夹、文件夹内图标和工作台应用页共用一项缩放百分比，并不是每个位置都能分别设置大小。普通 All Apps 和搜索页不在这项统一缩放范围内。

## Dock 与多任务

下面各项都以 LiquidDock 总开关开启为前提，但功能开关并不相同。

| 设置 | 生效条件与范围 |
| --- | --- |
| Dock 尺寸、位置、图标间距等自定义参数 | 开启 Dock 自定义；支持的液态玻璃背景接管 Dock 后使用对应玻璃路径 |
| Dock 描边 | 开启描边，独立于 Dock 尺寸自定义 |
| Dock 整体阴影 | 同时开启 Dock 自定义和阴影 |
| 描边阴影 | 同时开启描边和描边阴影 |
| 自定义分隔线 | 开启分隔线，独立于 Dock 尺寸自定义 |
| 隐藏手机互联入口 | 自身开关；只隐藏入口，不改变系统互联状态 |
| 最近应用黑名单 | 过滤系统 Dock 最近应用推荐源，不隐藏工作区图标；不依赖 Dock 自定义 |
| 工作台 Dock 尺寸和图标几何 | 开启工作台自定义，并在系统工作台模式中有对应的显示对象 |
| 多任务背景模糊 | 总开关即可，不要求液态玻璃 |
| 取消多任务壁纸压暗 | 开启该选项，不要求液态玻璃；保留系统模糊和过渡动画 |

Dock 液态玻璃背景与 Dock 尺寸自定义使用不同开关。多任务背景调整也与多任务操作按钮玻璃分开控制。

## 液态玻璃

桌面玻璃需要同时开启 LiquidDock 总开关和液态玻璃总开关。工作区图标、Dock 功能图标、小组件、小文件夹、大文件夹和多任务操作按钮还分别受各自开关控制。拖动玻璃同样受对应对象类型开关约束，并非所有拖动物体都会自动启用。

模糊、折射、色散、颜色和高光等参数用于已经启用的玻璃表面，修改参数本身不会打开功能。具有局部外观配置的表面按对应配置选择全局或局部值。

快捷菜单玻璃与白色文字/图标模式使用两个开关，两者都要求上述总开关开启，但文字模式不要求菜单玻璃开关开启。

卸载、移除和二次确认弹窗需要再开启弹窗玻璃；原生深色模式还要求深色模式开关和目标桌面的主题桥接可用。

小组件内部背景隐藏规则与玻璃外观是不同的数据。可以扫描实际桌面组件并选择背景目标，规则支持单独导入导出。

### 扩展界面

| 玻璃功能 | 条件 |
| --- | --- |
| 应用顶部窗口控制菜单 | 总开关 + 玻璃总开关 + 顶部菜单玻璃开关，目标系统动画适配可用 |
| 安全中心侧边栏 | 总开关 + 玻璃总开关 + 安全中心玻璃开关，目标 `:ui` 进程与材质适配可用 |
| MIUI 系统搜索主背景 | 总开关 + 玻璃总开关 + 对应第三方玻璃配置开启 |
| Gboard 悬浮键盘与已适配工具栏 | 总开关 + 玻璃总开关 + 对应第三方玻璃配置开启 |

这些是指定界面的适配，不会统一替换整个应用的背景。

Gboard 底栏拖动后是否进入大小调整由独立设置控制，该触摸策略不读取玻璃开关；它依赖底栏结构识别和适配安装成功。关闭自动调整后保留拖动，在抬手时阻止进入大小调整界面。

壁纸 GPU 渲染适配需要总开关、玻璃总开关和壁纸闪烁修复开关同时开启，还需 System Framework（`system`）作用域并重启设备。

## 安装与生效

从 [GitHub Releases](https://github.com/yu4032/LiquidDock/releases) 下载正式 APK，安装并在支持 libxposed API 101 的 LSPosed 中启用模块。代码主要适配 HyperOS 3.0.307+ 平板路径和 `com.miui.home` release-4.50.x.x；其他版本需要对应结构可用。

| 作用域 | 用途 |
| --- | --- |
| `com.miui.home` | 桌面、Dock、网格、多任务和桌面玻璃 |
| `com.android.systemui` | 解锁转场通知、可选的应用顶部菜单玻璃 |
| `com.miui.securitycenter` | 安全中心侧边栏适配 |
| `com.google.android.inputmethod.latin` | Gboard 适配 |
| `com.android.quicksearchbox` | MIUI 系统搜索适配 |
| `system`（System Framework） | 可选的壁纸 GPU 渲染适配 |

勾选作用域只允许模块进入相应进程，不会替你打开功能开关。安装后重启设备。布局、图标大小及其他启动时读取的设置需要重启相应进程；部分视觉状态支持运行时更新，不代表所有参数即时生效。

升级或更改网格前请备份系统桌面布局。LiquidDock JSON 导入导出保存模块配置，不是系统桌面布局备份；小组件背景隐藏规则另有独立备份。首次无配置时写入内置默认配置，普通升级不以默认值覆盖已有设置，手动恢复默认配置则会改变设置。
