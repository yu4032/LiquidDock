# LiquidDock v2.7.3

## 新增：展开文件夹液态玻璃

- 展开后的文件夹现可使用独立液态玻璃背景，并保留 Launcher 原生的展开、关闭动画与交互。
- 在「外观 → 玻璃组件 → 文件夹」中单独开关此功能，调节内部模糊、折射率、玻璃厚度、染色透明度和外部原生模糊程度。
- 文件夹玻璃与多任务切换、撤回手势和 Dock 动画衔接；展开后的图标保持原生尺寸，不受全局缩放影响。

## 优化与修复

- 工作区玻璃进入多任务时与桌面图标同步淡出。
- 改善长时间锁屏后的工作区玻璃恢复。
- 多任务「取消壁纸压暗」覆盖更多系统原生压暗路径。

## 升级提醒

- 本功能针对 HyperOS 3 / Launcher 4.50 适配。升级前建议备份桌面布局，安装后重启系统桌面以加载新增 Hook。
- 2×2 大文件夹占位、文件夹预览图标大小和原生描边开关已在 v2.7.2 发布，不属于本次新增。
