# LiquidDock v2.7.2

> 2026-10-15。基于 v2.7.1 之后已合并到主线的七项变更整理。

## 真实 2×2 大文件夹

- Launcher 4.50 的四宫格、九宫格大文件夹支持真实 2×2 桌面占位。
- 在桌面原生文件夹设置中，可按文件夹开启真实大文件夹和标题，保留原生尺寸选项、推荐开关及打开/关闭动画。
- 修复拖动后的标题显示，并调整九宫格预览中大图标和右下角小图标组的尺寸与间距。
- 「外观 → 文件夹」新增内部图标大小调节，范围 60%–110%，默认 100%；即时生效，独立于玻璃开关，保持文件夹占位、背景和标题不变。
- 可关闭原生大文件夹描边，并修复关闭后灰色描边偶尔重新出现的问题。
- 修复编辑模式下跨桌面页面移动后，文件夹背景和预览缩回原始大小的问题。
- 统一初次加载、编辑、跨页移动时的 2×2 尺寸处理；锁定布局时长按文件夹，继续保留自定义尺寸。

## 原生高级材质

- 修复小组件进入应用再返回桌面后的原生高级材质恢复，改善 MAML 重载和深色内容恢复。
- 改善文件夹原生高级材质的生命周期处理；关闭玻璃时交由桌面恢复原生材质。

## 升级提醒

升级前建议备份桌面布局，安装后重启桌面以加载新增 Hook。
